# NaC Website starten

## Windows

1. Node.js 20+ installieren.
2. Diesen Ordner entpacken.
3. `START-WINDOWS.bat` doppelklicken.
4. Danach die von Vite angezeigte lokale Adresse öffnen, normalerweise `http://localhost:5173`.

## Terminal

```bash
npm install
npm run dev
```

Wichtig: `apps/web/index.html` nicht direkt per Doppelklick öffnen. Das Projekt ist eine Vite-Anwendung und muss über den Vite-Dev-Server gestartet werden.
