# NaC — Nations and Civilizations: Age of Dragons

Next-generation website architecture for the NaC Minecraft project.

## Stack

- TypeScript
- React + Vite
- Tailwind CSS
- React Router
- TanStack Query
- Zustand
- Zod
- shadcn/ui / Radix UI
- Three.js / React Three Fiber
- MapLibre GL JS
- NestJS + Fastify
- PostgreSQL + Prisma
- Vitest + Testing Library + Playwright

## Development

```bash
npm install
npm run dev
npm run build
npm run preview
npm run test
```

The public web application lives in `apps/web`.
The future API lives in `apps/api`.

This repository is intentionally prepared for future seasons, live data, maps,
nations, players, lore, releases, documentation, media, and community features.
